### 🚀 Selected work

| Project | What it is | Stack |
|---|---|---|
| 🎮 **[emulator](https://github.com/sahuishan01/emulator)** | An original Nintendo Switch emulator written from scratch, targeting Android on a Mali Immortalis-G720 GPU. Early development. | Rust · Vulkan · Android |
| 🎲 **[BoardEmpire](https://github.com/sahuishan01/BoardEmpire)** | An original multiplayer board game: one deterministic rules engine drives a 2D board and a 3D "living city". Solo, LAN or online, with bots and replays. | C# · .NET 8 · Godot · Blazor WASM |
| 🐦 **[luckybird](https://github.com/sahuishan01/luckybird)** | A tiny modal terminal code editor with tree-sitter highlighting and LSP support for about 30 languages, in a release binary under 1 MB. | Rust · tree-sitter · LSP |
| 💡 **[3dRenderer](https://github.com/sahuishan01/3dRenderer)** | A real-time GPU ray tracer with a BVH, glass and mirror materials and procedural clouds. Runs natively and in the browser. | Rust · wgpu · WGSL · WebGPU |
| 📁 **[Flurer](https://github.com/sahuishan01/Flurer)** | A fast, lightweight file manager on native webviews instead of bundled Chromium, with tabs, dual pane and plugins. | Rust · Tauri v2 · SolidJS |
| 📈 **[Trader](https://github.com/sahuishan01/Trader)** | A paper-trading desk fed by live Binance market data, with a rule-based scalping bot and a live dashboard. No real money. | Rust · Axum · React · SQLite |
| 📒 **[Khata](https://github.com/sahuishan01/Khata)** | A self-hosted finance tracker: bank statement import, SMS auto-capture on Android, and row-level security per user. | Rust · PostgreSQL · React · Kotlin |
| 🎙️ **[TrueCalling](https://github.com/sahuishan01/true-caller)** | Fully offline group voice calls over Wi-Fi or a hotspot, for Android and iOS. | TypeScript · WebRTC · React |
| 🐝 **[streambree](https://github.com/sahuishan01/streambree)** | Peer-to-peer screen, camera and file streaming between your own devices, working behind CGNAT. | Rust · WebRTC · React |
| ⛵ **[Skiff](https://github.com/sahuishan01/skiff)** | Peer-to-peer file sharing for Android: pair with a 6-digit code, direct TCP with a streaming relay fallback. | Kotlin · Compose · Rust |
